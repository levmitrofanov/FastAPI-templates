## Описание проекта
Данный проект представляет собой веб-приложение на базе фреймворка **FastAPI** с интеграцией механизма шаблонизации **Jinja2**. В проекте реализовано отображение данных и ответов API на веб-страницах с использованием наследования шаблонов, Bootstrap CSS и форм добавления задач.

## Структура проекта
```text
todos/
├── templates/
│   ├── home.html         # Базовый родительский шаблон со стилями Bootstrap и navbar
│   └── todo.html         # Дочерний шаблон (форма ввода, список задач и карточка задачи)
├── api.py                # Главный исполняемый модуль приложения FastAPI
├── model.py              # Pydantic-модели данных (Todo, TodoItem, TodoItems, Todo.as_form)
├── todo.py               # Маршрутизатор APIRouter с интеграцией Jinja2Templates
├── requirements.txt      # Зависимости проекта
├── .gitignore            # Исключения системы контроля версий Git
└── README.md             # Документация проекта
```

## Установка и запуск

1. **Создание и активация виртуального окружения:**
   ```bash
   python -m venv venv
   source venv/Scripts/activate  # Для Windows
   ```

2. **Установка зависимостей:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Запуск сервера разработки:**
   ```bash
   uvicorn api:app --host 0.0.0.0 --port 8000 --reload
   ```

4. **Доступ к приложению:**
   - Веб-страница задач: [http://127.0.0.1:8000/todo](http://127.0.0.1:8000/todo)
   - Детальный просмотр задачи: [http://127.0.0.1:8000/todo/1](http://127.0.0.1:8000/todo/1)
   - Интерактивная документация Swagger UI: [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)
